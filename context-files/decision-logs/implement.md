2026-09-25  feature/w2-localhost-hardening  — Allow writes with neither `Origin` nor `Sec-Fetch-Site` — rejected requiring one — browsers always send one cross-site, so absence means a non-browser client (curl) that already runs as the user; keeps the documented curl examples working.

2026-09-25  feature/w2-localhost-hardening  — /setup: validation failures and mkdir failures now return 400 (was 200) and only newly created dirs are chmod 0700 — rejected chmod-ing an existing dir — its permissions belong to the user.
