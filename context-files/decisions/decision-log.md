# Decision Log

- **m0-react-scaffold**: ADR 0006 — adopt React + Vite + Tailwind + lucide-react for `@ibai/web`. Chose widely-used STABLE lines over newest majors for a de-risking scaffold: React 18 (not 19), Vite 5 (not 8), Tailwind 3 with classic `theme.extend` (not 4's CSS-first) so design tokens live as theme extensions later pages reuse; @vitejs/plugin-react 4. All deps pinned exact. UI placed in `packages/web/web-ui/` (Vite → `dist-ui/`) kept SEPARATE from the server tsc build (`dist/`) so both pipelines coexist; server serves the bundle at a NEW `/app` route so existing server-rendered pages stay untouched (M0 = shell only, no features). Config files renamed to `.cjs` because `@ibai/web` is `type:module`; Tailwind `content` globs + PostCSS `config` path made absolute via `__dirname` because Vite runs with `root=web-ui` but Tailwind/PostCSS auto-discover from CWD (root) — without this, purge emptied the CSS. Integrated `build:ui` into root `build` and a `tsc --noEmit` UI typecheck into root `typecheck` so `npm run verify`/CI cover the .tsx and produce the servable bundle. Added ESLint override (react + react-hooks) scoped to `web-ui/**` without weakening base rules. Added project `.npmrc` pinning the public npm registry (the user/CI `~/.npmrc` pointed at an expired CodeArtifact token, which would break `npm ci`); the existing lockfile already resolved against public npm. `dist-ui/` git-ignored. Verified from CLEAN `npm ci` → `npm run verify` GREEN (24 files/408 tests incl. lint+format+build) and live server curl: `/app` 200 serving local `/app/assets/*` with no external CDN URLs, `/app` assets 200 with correct content-types, `POST /app` 405, `/` and `/catalog` still 200, and bundle-absent graceful 200. Rejected: Next.js (implies render server; conflicts with thin-front-end + server-owns-storage).

- **cookie-persistence**: Session cookie was root cause of path not surviving browser restart; fixed by adding Max-Age=31536000 for ~1 year persistence.

- **ai-eval-engine**: ADR 0005 D6 implementation: coach()/CoachInput contract changed to AI-evaluation (model evaluates candidate's typed answers, returns structured per-topic verdicts, fail-closed on malformed output). EchoDemoProvider removed (supersedes ADR 0004). Provider now REQUIRED (Anthropic or Ollama).

- **ai-interview-ui**: Step 5b complete. Self-assess Pass/Fail removed (charter 6.2: model evaluates, not user). Turn-by-turn AI interview feeding coach() answers→evaluations. POST /coach + /coach.json ungated. Provider-required friendly state (200 config page, not 4xx error). Fail-closed friendly error handling (isConnectionError, isAuthError, malformed output → 502 with helpful message, no writes). README updated: removed zero-config/demo references, documented provider requirement (Anthropic or Ollama). Last deferred roadmap item: bulk-import of founder's Notion intuitions.
