# InterviewBudAI
InterviewBudAI (pronounced Interview Buddy) is an AI assisted Interview prep agent that allows you to more effectively make use of your Interview prep materials and gain insights on your personal strengths and weaknesses

## Web Front-End (Local ASSESS)

The `@ibai/web` package provides a locally-hosted web server for the ASSESS capability. See [packages/web/README.md](packages/web/README.md) for usage details.
